# 🧠 براین‌باکس (BrainBox)

یک اپلیکیشن دسکتاپ امن که با پایتون برای مدیریت رمزهای عبور و یادداشت‌های شما ساخته شده است.

## 🚀 امکانات

- **ذخیره امن اطلاعات:** محافظت از اطلاعات حساس و محرمانه شما.
- **رابط کاربری مدرن:** محیطی زیبا، ساده و کاربرپسند.
- **ساخته شده با پایتون:** توسعه‌یافته با پایتون و کتابخانه‌های به‌روز.
